1. PROJE NEDİR?
─────────────────────────────────────────────
"ADS Guardian" adlı gerçek zamanlı bir siber güvenlik izleme sistemidir.
Nginx web sunucusuna gelen HTTP isteklerini anlık olarak analiz ederek
DoS, Brute Force, SQL Injection ve MITM saldırılarını tespit eder.
Web tabanlı bir dashboard ile tüm trafiği canlı gösterir.

Teknoloji yığını:
  - Backend : Python, Flask, Flask-SocketIO (gerçek zamanlı iletişim)
  - Frontend: HTML/CSS (Tailwind), JavaScript, Chart.js
  - ML      : scikit-learn (Random Forest, Logistic Regression)
  - Altyapı : Docker (hedef nginx konteyneri)


─────────────────────────────────────────────
2. VERİ SETİ — CIC-IDS2018
─────────────────────────────────────────────
Kullanılan veri seti: Canadian Institute for Cybersecurity tarafından
hazırlanan gerçek ağ trafiği kaydı (CIC-IDS2018).

Veri seti özellikleri:
  - Günlük CSV dosyaları halinde (02-14-2018.csv, 02-15-2018.csv vb.)
  - Her satır = bir ağ akışı (flow)

  - Etiketler: DoS, BruteForce, Benign ve diğerleri

Dosya: ml_pipeline/clean_dataset.py

4. MODEL EĞİTİMİ — İKİ AŞAMA
─────────────────────────────────────────────

── 4a. İlk Model (train_model.py) — CIC özellikleri ile ──────────────

  - Tüm 80+ sayısal özellik kullanıldı
  - NaN ve sonsuz değerler → 0 ile dolduruldu
  - Zaman damgası kolonu → çıkarıldı
  - StandardScaler ile ölçekleme
  - LabelEncoder ile etiket kodlama
  - %80 eğitim / %20 test bölmesi (stratify=True → dengeli bölme)
  - Model: RandomForestClassifier (100 ağaç, n_jobs=-1)

── 4b. İkinci Model (train_cic_http.py) — HTTP Feature Mapping ────────

  Bu modelde CIC özelliklerini gerçek Nginx log özelliklerine çevirdim.
  Çünkü sistem gerçekte Nginx log'larını okuyacak, CIC akışlarını değil.

  Feature Mapping tablosu:
    CIC Özelliği          → HTTP Özelliği
    ─────────────────────────────────────
    Flow Pkts/s × 60      → requests_per_ip_last_60s
    TotLen Fwd Pkts       → bytes_sent
    Dst Port (80/443→200) → status_code
    Protocol (6=TCP→0)    → method_encoded
    Fwd Seg Size Avg/300  → path_depth
    Pkt Len Mean / 5      → user_agent_length

  Bu model production'da kullanılan model → dos_model.pkl olarak kaydedildi.

Kütüphane: scikit-learn

7. SQLi TESPİTİ (feature_extractor.py içinde)
─────────────────────────────────────────────
SQL Injection kural tabanlı + skor sistemi ile tespit edilir:

  a) Keyword skoru: "union", "select", "drop", "sleep(" vb. anahtar
     kelimeler URL'de aranır, her eşleşme belirli ağırlık ekler

  b) Karakter skoru: %27 (tek tırnak), %22 (çift tırnak), -- gibi
     URL-encoded tehlikeli karakterler aranır

  c) Regex pattern skoru: "UNION SELECT", "OR 1=1", "sleep(",
     "information_schema." gibi yüksek güvenilirlikli kalıplar

  d) Ağırlıklı toplam:
     anomaly = pattern×0.60 + keyword×0.25 + char×0.15
     Eşik: 0.50 → altı normal, üstü saldırı

8. DASHBOARD (dashboard.py + dashboard.html)
─────────────────────────────────────────────
Flask backend 1400+ satır, şu endpoint'leri sağlar:

  GET  /               → Dashboard ana sayfası
  GET  /api/stats      → İstatistikler (toplam istek, saldırı sayısı)
  GET  /api/logs       → Son 500 log satırı
  GET  /api/attacks    → Aktif/son saldırı oturumları
  GET  /api/health     → Sistem sağlık durumu (container, model durumu)
  POST /api/test/offline → RAM'de test (gerçek Docker trafiği yok)
  POST /api/test/live  → Docker konteynerine gerçek HTTP saldırısı başlatır

Gerçek zamanlı iletişim: Flask-SocketIO (WebSocket)
  - Her yeni log satırı → "log_entry" event
  - Her saldırı tespiti → "attack_detected" event
  - İstatistik güncellemesi → "stats_update" event

10. DoS SALDIRI TEST ARACI (dos/attack.py)
─────────────────────────────────────────────
Bağımsız bir HTTP flood scripti — sadece test amaçlı:

  Parametreler:
    --url       Hedef URL (varsayılan: http://localhost:8080)
    --threads   Eşzamanlı thread sayısı (varsayılan: 10)
    --duration  Saldırı süresi saniye (varsayılan: 30)

  Çalışma mantığı:
    - Her thread sürekli HTTP GET isteği gönderir
    - stop_event ile belirlenen süre sonunda durur
    - Ekrana başarı/hata sayısı özetini basar

  Kütüphane: requests, threading
